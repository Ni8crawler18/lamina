Contract roles
--------------
  LaminaFactory  — deploys a compliant RWA token + an audit topic in one tx
  AuditLog       — access-controlled, append-only on-chain audit trail
  LaminaRWAToken — ERC-3643-style permissioned compliance token
                   (deployed per asset at runtime via the factory; not a fixed address)
  USDC           — settlement asset for coupons & principal

Note: Base, Arc, Avalanche and Ethereum Sepolia share the same Factory/AuditLog
addresses. This is expected — they were deployed by the same operator at the same
nonce, so CREATE produces identical addresses across chains (deterministic).
