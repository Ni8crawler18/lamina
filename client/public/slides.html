Future Roadmap

Key learnings & next steps

Learnings from building Lamina

OFAC Screening Tuning

Fuzzy matching against 18K+ SDN entries requires careful threshold calibration. Started at 85%, moved to exact match for production reliability. Fuzzy matching works best with longer entity names.

Hedera SDK Maturity

hiero-sdk-python is new but capable. Transaction freezing patterns, receipt handling, and mirror node queries all work reliably on testnet.

Agent Orchestration

Claude API with tool_use enables powerful NL command parsing. Structured tool definitions map cleanly to Hedera operations.
