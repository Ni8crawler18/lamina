Architecture

Four autonomous agent modules

Lifecycle Agent

Asset issuance, token deployment, coupon scheduling, NAV updates from treasury yields, maturity redemption and token burns.

Compliance Agent

KYC whitelist management, jurisdiction enforcement (SEC Reg D/S, MiFID II), OFAC SDN screening, transfer validation.

Reporting Agent

Quarterly compliance reports, investor statements, audit trail compilation. PDF generation from on-chain data.

Chat Agent

Natural language interface powered by Claude. Fund managers issue commands in plain English — the agent orchestrates.
